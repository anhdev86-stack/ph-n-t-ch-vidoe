01

Pipeline thật của Kaloclip

8 bước lộ ra ở màn hình "Đang tối ưu hóa". Đây là trình tự xử lý gốc — đọc từ trái sang phải, trên xuống dưới.

01
Trích xuất video
Tải video, tách frames + audio track.
02
Phân loại video
Nhận diện loại: review / bán hàng / unboxing.
03
Phân tích hình ảnh
Vision model xem keyframes đại diện.
04
Phân tích âm thanh
Tách giọng khỏi nhạc nền.
05
Nhận diện ngôn ngữ
Detect tiếng Việt → chọn model ASR.
06
Phân tích cấu trúc kịch bản
LLM gom transcript thành phân đoạn marketing.
07
Khớp đặc điểm dữ liệu
Đồng bộ timestamp: hình ↔ lời ↔ phân đoạn.
08
Tạo kết quả cuối cùng
Render bảng + sinh phần phân tích. Cache lại.
02

Pipeline đề xuất cho anh HYBRID

Gộp 8 bước Kaloclip thành 4 khối. Tự host chỗ tiếng Việt dễ sai (ASR), gọi API chỗ cần suy luận (vision + marketing).

① INGESTffmpeg
Tách audio.wav + trích keyframes theo scene-change (select='gt(scene,0.3)').
② ASRSpeech → text
PhoWhisper / Whisper large-v3 self-host → transcript có timestamp. Chỗ dễ sai nhất với tiếng Việt bán hàng → tự host để chuẩn.
③ VISIONFrame → mô tả
Mỗi keyframe → Claude / Gemini vision API gán cỡ cảnh + mô tả hình ảnh.
④ SEGMENT + PHÂN TÍCHLLM reasoning
Claude API gộp transcript+visual → cắt đoạn theo khung marketing, rồi sinh "điểm thành công". Kết quả cache theo video_id.

05

Prompt xương sống

Ba lời gọi model. Copy về chỉnh nhẹ là chạy được.

Vision · mô tả keyframebước ③
# Xem khung hình, trả JSON
{
  "shot_type": // chọn ĐÚNG 1: Toàn cảnh|Viễn cảnh|Trung cảnh|
              //              Trung cận cảnh|Cận cảnh|Đặc tả
  "visual_desc": // 1-2 câu: ai/vật, đang làm gì, sản phẩm nào lộ rõ
}
Chỉ mô tả cái NHÌN THẤY — không suy diễn lời thoại.
Segment · cắt đoạn theo khungbước ④a
# INPUT: transcript(+timestamp) & visual(+timestamp)
Cắt video thành PHÂN ĐOẠN theo dòng chảy bán hàng.
Mỗi đoạn gán section_type ∈ {hook, usp, product_info,
  experience, how_to, social_proof, cta}.
Đặt section_name tiếng Việt hấp dẫn.
→ trả mảng {section_name, section_type, start, end,
            shot_type, visual_desc, transcript}
Analysis · điểm thành côngbước ④b
# INPUT: storyboard đã cắt đoạn
1) "Giải thích điểm thành công": 4-6 gạch đầu dòng,
   mỗi dòng = 1 ĐÒN BẨY tâm lý (tò mò, giá trị,
   USP, niềm tin, khan hiếm+CTA) + cách video dùng nó.
2) "Kỹ thuật quay phim": cỡ cảnh chủ đạo, chuyển
   động máy, zoom chi tiết, bố cục đặt sản phẩm.
06

Chọn stack

Bắt đầu nhanh bằng API, nâng cấp độ chính xác tiếng Việt bằng self-host khi volume lớn.

Phương án A

Gemini native video

Ingest thẳng file video → 1 JSON có cả transcript, mô tả, cỡ cảnh, phân đoạn. Gộp bước 1–7 thành 1 call. MVP trong 1 ngày, không GPU.

KHUYẾN NGHỊ
Phương án Lai

Whisper + API vision/LLM

PhoWhisper tự host cho ASR tiếng Việt chuẩn + Claude/Gemini cho vision & suy luận marketing. Cân bằng chi phí và độ chính xác.

Phương án B

Tự host toàn bộ

Whisper + scene-detect + vision mã nguồn mở. Rẻ nhất dài hạn, chính xác nhất, nhưng cần GPU và nhiều bước vận hành.
